
# Yandex API Stand Tests

Проект автоматизированного тестирования API
сервиса Яндекс Прилавок.

## Описание

В проекте реализованы 12 API-тестов
на создание пользователя.

Проверяются:
- Допустимая длина имени.
- Недопустимая длина имени.
- Русские и латинские буквы.
- Пробелы и специальные символы.
- Цифры в имени.
- Отсутствие обязательного параметра.
- Пустое значение имени.
- Передача числа вместо строки.

## Технологии

- Python
- pytest
- requests
- Git

## Установка

Установить зависимости:

python -m pip install -r requirements.txt

Создать файл configuration.py на основе
configuration.example.py и указать адрес
своего учебного стенда.

## Запуск тестов

python -m pytest create_user_test.py -v

## Результаты

Некоторые тесты могут завершаться FAILED,
если поведение API не соответствует требованиям.
